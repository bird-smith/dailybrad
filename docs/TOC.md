# Roadmap

Every feature in build order, one line each. Detail lives in the plans.

- Each line is one plan: `docs/plans/<section>/<section>.<n>-<name>.md`.
- A line looks like `- [ ] [ ] [ ] 1.1-brew-log: saving brews, with backup`.
- Every line stays **under 90 characters**, boxes included.
- Three boxes, ticked left to right: **written**, **improved**, **built**.
  - `[ ] [ ] [ ]` stub only: write it
  - `[x] [ ] [ ]` written: improve it
  - `[x] [x] [ ]` improved: build it
  - `[x] [x] [x]` built
- A plan that needs revising goes back: clear boxes from the right.

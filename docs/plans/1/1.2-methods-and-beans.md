## Scope

- Add, edit and remove the brewing methods he uses (Hario Switch, V60 and so on).
- Add and edit beans: roaster, roast date, name, bag size, cost, region, varietal, notes.
- Mark a bag finished so it leaves the bean picker; set one bean as active.
- The home screen shows the active bean and days since its roast.
- If saving fails, a plain message says so and keeps what he typed (the pattern later
  plans reuse).

**Not in this plan:** cups left and cost per cup (`1.x-brew-log.md`), recipes.

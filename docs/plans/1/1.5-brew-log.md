# Plan: Saving brews and the history list

**Status:** stub, not written yet
**Outline:** `docs/outlines/coffee-tracker.md`, sections "The first version" (Brew logging, Beans), "Rules and worked example"
**Depends on:** `1.x-brew-setup.md`

## Scope

- Save a brew with everything used: bean, days since roast, method, recipe and settings.
- Settings are copied at save time, so editing a recipe later never changes past brews.
- A history list (side by side with a brew's details on desktop); fix or delete a brew.
- Each bean shows roughly how many cups are left and its cost per cup.

**Not in this plan:** the timer (`1.x-brew-timer.md`), ratings (`1.x-ratings.md`).
